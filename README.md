## Оценка долей происхождения человека при помощи предкового графа рекомбинаций

Работа посвящена подходу к решению задачи оценки долей вклада популяций в происхождение особи. Метод опирается на структуру наследования, описываемую предковым графом рекомбинаций (ARG).

В предлагаемой модели доля примешивания рассматривается как параметр теоретического распределения, определяемого на структуре графа. Такой подход позволяет оценивать вклад популяций, не имея явной истории миграций, а опираясь исключительно на наблюдаемые геномные данные.

## Estimating Ancestry Proportions Using an Ancestral Recombination Graph

This work presents an approach to estimating the contributions of different populations to an individual's ancestry. The method is based on the inheritance structure described by an Ancestral Recombination Graph (ARG).

In the proposed model, the admixture proportion is treated as a parameter of a theoretical distribution defined over the graph structure. This approach enables estimation of population contributions without requiring explicit migration history, relying solely on observed genomic data.
